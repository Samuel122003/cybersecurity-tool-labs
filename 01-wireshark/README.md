# Lab 01 - Wireshark Network Traffic Investigation

## Objective

Learn how to capture, filter, and analyze network traffic using Wireshark.

## Environment

- Windows
- Wireshark
- Local lab network

## Skills Practiced

- Capturing network traffic
- Using Wireshark display filters
- Identifying source and destination IP addresses
- DNS analysis
- TCP analysis
- Investigating suspicious network connections

## Scenario

A workstation is experiencing unusual network activity. The goal of this lab is to analyze the traffic and determine what normal and potentially suspicious activity looks like.

## Investigation

### Interface Selection

Wireshark displayed several interfaces, including Wi-Fi, multiple Local Area Connections, and a loopback capture adapter.

I identified Wi-Fi as the likely active interface because its traffic activity increased when I opened a website in my browser.
### Initial Traffic Capture

I captured normal browsing traffic on the Wi-Fi interface.

The main protocols observed were:

- TCP
- UDP
- TLS
- DNS

This established a baseline of normal network activity before applying more specific filters.
