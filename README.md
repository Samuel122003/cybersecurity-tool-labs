# Cybersecurity Tool Labs

A hands-on learning path focused on developing practical experience with common cybersecurity tools and SOC investigation workflows.

## Goal

Build practical skills in network analysis, SIEM investigation, endpoint security, vulnerability management, web security, and threat detection through progressively more difficult labs.

## Learning Path

- [ ] Lab 01 - Wireshark
- [ ] Lab 02 - Nmap
- [ ] Lab 03 - Snort
- [ ] Lab 04 - Splunk
- [ ] Lab 05 - Microsoft Sentinel
- [ ] Lab 06 - Microsoft Defender XDR
- [ ] Lab 07 - Sysinternals
- [ ] Lab 08 - Nessus
- [ ] Lab 09 - Burp Suite
- [ ] Lab 10 - Zeek / Suricata
- [ ] Lab 11 - Sigma / YARA
- [ ] Lab 12 - Final SOC Investigation

## Final Project

The final project will combine multiple cybersecurity tools to investigate a simulated security incident from initial detection through investigation, containment, MITRE ATT&CK mapping, and incident reporting.
